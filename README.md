# Java OOP lecture notes

A study archive for Java programming and object-oriented programming. The repository currently contains `Java_Lec1_merged.pdf`, a 370-page set of lecture notes beginning with Java basics, the JVM, and Java APIs, alongside its editable Xournal++ source, `Java_Lec1_merged.xopp`.

## Use

Open the PDF in any PDF reader to study or search the material. Open the `.xopp` file in Xournal++ to edit or annotate the original notebook. The repo currently contains notes rather than executable Java source, so there is no install, build, or run command. If examples are added later, document their Java version and compilation steps here.
